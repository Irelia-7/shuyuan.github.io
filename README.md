# Personal Homepage

This is a static academic personal homepage scaffold for GitHub Pages.

## Preview locally

Open `index.html` directly in a browser.

No build step, package manager, backend, or framework is required.

## Fill in your content

- Replace `Your Name` in `index.html` with your real name.
- Replace the position, affiliation, biography, contact details, and profile links.
- Replace `assets/profile-placeholder.svg` with your portrait, then update the `img src` if the filename changes.
- Put your CV in `assets/` and update the CV link.
- Edit the research directions in the `Research` section.
- Edit publication entries in the `Publications` section, grouped by year.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Put these files at the repository root.
3. Push to the `main` branch.
4. Open repository Settings.
5. Go to Pages.
6. Under Build and deployment, choose `Deploy from a branch`.
7. Select `main` and `/root`, then save.

GitHub Pages may take a few minutes to publish the site.
